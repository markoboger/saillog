# saillog

A sailing logbook, built step by step in Programmiertechnik I (HTWG Konstanz, Scala 3.9.0).

| Tag | Lecture | Content |
|---|---|---|
| `v19-files` | 19 Files and File Formats | domain model, GPX/CSV parsing, JSON with uPickle |
| `v20-db` | 20 Databases | repository trait, JSON file + SQLite (ScalaSql) |
| `v21-http` | 21 HTTP Server | REST API with Cask, track upload |
| `v22-html` | 22 HTML | HTML pages from strings, form, SVG track |
| `v23-css` | 23 CSS | stylesheet, static files |
| `v24-templates` | 24 HTML Templates | Scalatags pages |

Run: `sbt "runMain saillog.lecture19"` (requires JDK 17+).
